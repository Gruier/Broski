# 🛡️ Discord Moderation & Community Bot

Багатофункціональний Discord-бот на Python: модерація, захист від спаму й підозрілих посилань, верифікація, тікети, рівні та міні-економіка. Написаний на `discord.py` зі slash-командами та базою даних SQLite.

> Проєкт створений для навчання та портфоліо. Ідеї й пропозиції вітаються!

---

## ✨ Можливості

### 🛡️ Модерація
- Slash-команди: `/warn`, `/timeout`, `/kick`, `/ban`, `/unban`, `/clear`
- Система попереджень із базою даних: **3 попередження = автоматичний тайм-аут**
- `/slowmode`, `/lock`, `/unlock` для керування чатами
- Перевірка ієрархії ролей: бот не дозволить кікнути власника чи людину з вищою роллю

### 🔒 Автоматичний захист
- **Антиспам**: видаляє повідомлення, якщо учасник пише надто часто
- **Фільтр посилань** з білим списком доменів (ловить і трюки на кшталт `discord.com@evil.com`)
- **Фільтр заборонених слів** (список налаштовується)
- **Анти-рейд**: тривога в логах, якщо за кілька секунд заходить багато нових учасників
- **Позначка нових акаунтів** у логах (акаунт молодший за 7 днів)
- Бот ніколи не пінгує `@everyone` і ролі, навіть якщо хтось підсунув такий текст у команду

### 📋 Логи
Окремий канал `mod-logs`: входи й виходи, видалені та змінені повідомлення, дії модераторів, тривоги.

### ✅ Верифікація та підтримка
- Кнопка **«Я не бот»**, яка видає роль (працює і після перезапуску бота)
- **Тікети**: кнопка створює приватний канал із модераторами, а закрити його може автор або модератор

### 🏆 Спільнота
- **Рівні й досвід** за повідомлення: `/rank` (з прогрес-баром), `/top`
- **Економіка**: `/daily`, `/balance`, `/pay`, `/richest`
- **Розваги**: `/8ball`, `/roll`, `/coinflip`, `/poll`, `/avatar`
- **Сервіс**: `/help`, `/ping`, `/userinfo`, `/serverinfo`, `/announce`

## 🚀 Запуск

### 1. Підготовка
1. Встанови [Python 3.10+](https://www.python.org/downloads/) (на Windows познач **Add python.exe to PATH**).
2. Клонуй репозиторій:
   ```bash
   git clone https://github.com/Gruier/<Broski>.git
   cd Broski
   ```
3. Встанови залежності:
   ```bash
   pip install -r requirements.txt
   ```

### 2. Створення бота в Discord
1. Відкрий [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**.
2. Вкладка **Bot** → **Reset Token** → скопіюй токен.
3. Увімкни **Message Content Intent** і **Server Members Intent**.
4. **OAuth2 → URL Generator**: Scopes `bot` і `applications.commands`.
5. Дозволи бота (без Administrator):
   - Send Messages, Manage Messages, Read Message History
   - Kick Members, Ban Members, Moderate Members
   - Manage Roles, Manage Channels
   - Add Reactions, Embed Links
6. Відкрий згенероване посилання й додай бота на свій сервер.

### 3. Налаштування
Створи файл `.env` у корені проєкту:
```
DISCORD_TOKEN=сюди_вставиш_токен
```
> ⚠️ **Ніколи не публікуй токен.** Файл `.env` уже додано в `.gitignore`.

### 4. Підготовка сервера
- Створи приватний текстовий канал **`mod-logs`** і додай до нього роль бота.
- Створи роль **`Verified`**.
- Підніми роль бота **вище** за `Verified` у списку ролей.
- (Необов'язково) Створи роль **`Moderator`**, яка бачитиме тікети.

### 5. Запуск
```bash
python bot.py
```
Потім на сервері виконай `/setup_verify` і `/setup_tickets` у потрібних каналах.

## ⚙️ Налаштування

Усі параметри зібрані на початку `bot.py`:

| Параметр | Що робить |
|---|---|
| `LOG_CHANNEL_NAME` | Назва каналу для логів |
| `VERIFIED_ROLE_NAME` | Роль, яку видає кнопка верифікації |
| `ALLOWED_DOMAINS` | Дозволені сайти для посилань |
| `BAD_WORDS` | Список заборонених слів |
| `SPAM_LIMIT` / `SPAM_WINDOW` | Ліміт повідомлень за період |
| `WARN_LIMIT` / `WARN_TIMEOUT_MIN` | Скільки попереджень до тайм-ауту і його тривалість |
| `RAID_JOINS` / `RAID_WINDOW` | Чутливість анти-рейду |
| `XP_COOLDOWN`, `DAILY_REWARD` | Налаштування рівнів і економіки |
| `MODS_EXEMPT` | Чи звільняти модераторів від фільтрів |

## 🔐 Безпека

- Токен зберігається в `.env`, а не в коді
- Принцип мінімальних привілеїв: боту не потрібні права Administrator
- Команди модерації перевіряють права користувача та ієрархію ролей
- Заборонено пінги `@everyone` і ролей від імені бота
- Введення користувачів обмежене діапазонами (`Range`), щоб уникнути некоректних значень
